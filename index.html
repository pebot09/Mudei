Compartilhar & sincronizar

🔗 Link com os dados

Gera um link que carrega tudo (itens, tarefas, caixas, equipe). Mande no WhatsApp para quem está ajudando. Quem abrir pode mesclar com o que já tem.

🛒 Lista de compras em texto

Copia só os itens pendentes, organizados por categoria — bom para mandar para quem vai à loja.

💾 Arquivo de backup

Exporta um arquivo .json com tudo. Importe em outro aparelho (dá para mesclar ou substituir).

Com a sincronização automática ativa, o link com os dados só é preciso uma vez por aparelho (para conectar); depois tudo se junta sozinho pela internet. Cada celular também guarda uma cópia completa — o app funciona offline e ninguém perde nada.
